# Pidrilium (Fabric, Minecraft 26.3)

Белая руда **Пидрилий**:

- Руда (`pidrilium_ore`) генерируется только ниже Y=0 (от -64 до -1), в камне и глубинном сланце.
- Из руды выпадает **сырой пидрилий** (с Удачей — больше, с Шёлковым касанием — сама руда).
- Сырой пидрилий и саму руду можно переплавить в **печи** (или плавильне) в **пидриловый слиток**.
- Из слитков: **блок**, меч, кирка, топор, лопата, мотыга, шлем, нагрудник, поножи, ботинки.
- Все текстуры белые. Названия есть на английском и русском.

Крафт — стандартный (как у железа/алмаза): слитки + палки; блок 3x3 из слитков, из блока обратно 9 слитков.

## Сборка

Нужны JDK 25 и Gradle 9.5+ (либо возьмите `gradlew` из https://github.com/FabricMC/fabric-example-mod и положите рядом).

    gradle build

Готовый мод: `build/libs/pidrilium-1.0.0.jar` (не `-sources`). Положите его в папку `mods`
вместе с Fabric API 0.161.0+26.3 (Fabric Loader 0.19.5+).

## Сборка без установки Java и Gradle (через GitHub)

1. Зарегистрируйтесь на github.com и создайте новый репозиторий (New repository).
2. Нажмите «uploading an existing file» и перетащите в окно ВСЁ содержимое папки проекта,
   включая скрытую папку `.github` (если её не видно в проводнике, включите показ скрытых файлов).
3. Нажмите Commit changes, затем откройте вкладку Actions и дождитесь зелёной галочки (несколько минут).
4. Откройте завершённый запуск и внизу в разделе Artifacts скачайте `pidrilium-mod`.
   В архиве лежит готовый `.jar` для папки `mods`.

## Где что менять

- Характеристики инструментов/брони: `src/main/java/com/pidrilium/PidriliumMaterials.java`
- Частота и размер жил: `src/main/resources/data/pidrilium/worldgen/` (`count`, `size`)
- Текстуры: `src/main/resources/assets/pidrilium/textures/`
